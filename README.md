# Demo 2: Hearth & Honey Cafe (Cozy Local Cafe)

Warm, welcoming, community-focused. **Fictional demo brand. Every detail is a placeholder.**

## Preview
Double-click `index.html`.

## Change the basics
- **Name, phone, WhatsApp, map, opening hours:** edit the `CONFIG` block at the top of `script.js`. The "open now" line and today's highlighted row use `CONFIG.hours`, so update the visible hours in `index.html` as well.
- **Menu (Coffee / Bakery / Brunch tabs):** edit the lists in `index.html`.
- **Community events:** the three cards are demo ideas. Replace with real events or delete the section.
- **Colours:** variables at the top of `style.css`.
- **Photos:** search for `images.unsplash.com`. The gallery uses a small and a large URL per photo (`src` and `data-full`).

## Needs extra setup for a real business
- No online ordering or booking. WhatsApp and call buttons work once real numbers are set.
